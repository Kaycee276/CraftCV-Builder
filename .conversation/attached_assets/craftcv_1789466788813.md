# CraftCV — AI-Powered Conversational CV Builder

## MeDo AI Editor Requirements

---

## Project Overview

**CraftCV** is a web application where users have a natural conversation with an AI about their life, work, and achievements — and the AI builds their CV automatically from that conversation. No forms to fill. No templates to wrestle with. Just talk, and your CV writes itself.

Users sign up, chat with the AI about their background, click **"Generate My CV"** when ready, download a clean PDF, and optionally save it directly to Google Drive. They can return anytime, continue the conversation with new experiences, and regenerate an updated CV instantly.

## Authentication — Supabase

**Hard rule: No unauthenticated access to any CV feature.** Landing page is public. Everything else requires sign-in.

### Landing Page (`/`)

- Hero section: tagline, 2-sentence description, **"Get Started — It's Free"** CTA button
- Brief 3-step explainer: Chat → Generate → Download
- No pricing. No feature grid. Keep it tight.
- Footer: CraftCV wordmark + _"Built for job seekers across Africa and beyond"_

### Sign Up (`/signup`)

- Fields: Full Name, Email, Password, Confirm Password
- Validation:
  - Full name: 2–60 characters, letters and spaces only
  - Email: valid format
  - Password: minimum 8 characters, at least one uppercase letter and one number
  - Passwords must match
- No email confirmation (disabled in Supabase dashboard)
- On success: create `profiles` row in DB → redirect straight to `/chat`
- On duplicate email: _"An account with this email already exists."_ with link to sign in
- On weak password: inline hint under password field

### Sign In (`/signin`)

- Fields: Email, Password
- On wrong credentials: _"Incorrect email or password."_
- On success: redirect to `/chat` (restore previous session if exists)
- "Don't have an account? Sign up" link

### Auth Guards

- `/chat`, `/history`, `/settings` → redirect to `/signin` if unauthenticated
- Show full-page skeleton loader while auth state resolves
- Never flash unauthenticated UI to a logged-in user

### Sign Out

- Available in top-right nav dropdown
- On sign out: clear Supabase session → redirect to `/`

### No Password Reset

- No email service available. Show: _"To reset your password, please contact support."_ on sign-in page. No reset flow implemented.

### Feature 1 — Conversational AI Chat

The heart of the app. The entire left panel is a chat interface where users talk to the AI about their background.

#### Chat UI

- **Messages area**: Scrollable, fills available height. Newest message at bottom. Auto-scrolls on new message.
- **Input bar**: Fixed to bottom of chat panel. Textarea (auto-resizes, max 4 lines). Send button (black arrow icon). Submit on Enter (Shift+Enter for new line).
- **Typing indicator**: Animated three-dot bounce shown while AI is generating a response.
- **Message timestamps**: Shown subtly below each message (HH:MM format).
- **AI avatar**: Small black circle with white "AI" text, shown beside each AI message.
- **User avatar**: First letter of user's name in a black circle.

#### AI Behaviour & System Prompt

The AI acts as a warm, professional career coach. It asks smart follow-up questions to extract CV-worthy details the user might not think to mention. It organises information mentally and uses it when generating the CV.

**OpenAI-format API call:**

```javascript
// FreeModel — OpenAI-compatible format
// Base URL: https://api.freemodel.dev
// Model: gpt-3.5-turbo
// Auth: Bearer token

const FREEMODEL_API_KEY = import.meta.env.VITE_FREEMODEL_API_KEY;

const response = await fetch("https://api.freemodel.dev/v1/chat/completions", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    Authorization: `Bearer ${FREEMODEL_API_KEY}`,
  },
  body: JSON.stringify({
    model: "gpt-3.5-turbo",
    max_tokens: 600,
    messages: [
      { role: "system", content: SYSTEM_PROMPT },
      ...conversationHistory, // full history every request
    ],
  }),
});

const data = await response.json();
const reply = data?.choices?.[0]?.message?.content ?? "";
```

**System Prompt (inject as `SYSTEM_PROMPT` constant):**

```
You are a warm, professional career coach helping someone build their CV through conversation. Your job is to learn everything relevant about the user — their work experience, education, skills, achievements, certifications, languages, and career goals — through friendly, natural conversation.

Guidelines:
- Start by warmly greeting the user and asking them to tell you about themselves and what kind of role they're looking for.
- Ask one or two focused follow-up questions at a time — never overwhelm with a list of questions.
- Dig for specific achievements and numbers: "You mentioned managing a team — how many people? What did you achieve together?"
- Ask about: work experience (company, role, dates, responsibilities, achievements), education (institution, degree, year), skills (technical, soft), certifications, languages spoken, hobbies/interests (briefly), and career objective.
- If the user gives vague answers, gently probe: "Can you tell me a bit more about what that involved day-to-day?"
- Be encouraging. Treat everything the user shares as valuable.
- Keep your responses concise — 2–4 sentences max unless asking multiple questions.
- Never generate the CV yourself in the chat. When the user says they are done or asks to generate, tell them to click the "Generate My CV" button.
- If the user returns after a previous session and shares new experiences, warmly acknowledge what they've added and ask clarifying questions about the new information.
- Maintain context across the full conversation history provided to you.
- Never break character. Never discuss anything unrelated to building the user's CV.
```

#### Conversation Persistence

- Save every message (role + content + timestamp) to Supabase `messages` table in real time
- On returning to `/chat`, load full conversation history from DB and restore the chat
- The full conversation history is sent to the API on every request (stateless API, stateful DB)
- No message limit shown to user — but internally cap at last 80 messages sent to API to avoid token overflow (keep system prompt + last 80 messages)

#### Welcome State (first visit)

- If user has no previous messages, show a welcome card in the chat area:
  > _"Hi [Name] 👋 I'm your CV coach. Tell me a bit about yourself — what kind of work do you do, and what are you looking for?"_
- This welcome message is injected as the first AI message and saved to DB

### Feature 2 — Generate My CV Button

A persistent, prominent button visible at all times above the chat input bar.

- Label: **"✨ Generate My CV"**
- Style: Full-width black button, white text, in chat panel above the input bar
- Disabled state: when AI is currently responding
- On click:
  1. Show a full-screen loading overlay: _"Crafting your CV..."_ with an animated quill icon
  2. Make a **second API call** (separate from the chat) that sends the full conversation history with a CV generation prompt (see below)
  3. Parse the structured JSON response
  4. Render the CV preview in the right panel
  5. Dismiss the loading overlay
  6. Save the generated CV content to Supabase `cvs` table
  7. Show a toast: _"Your CV is ready!"_

#### CV Generation API Call

```javascript
const cvResponse = await fetch(

  {
    method: "POST",
    headers: {
      "Content-Type": "application/json",

    },
    body: JSON.stringify({
      model: "gpt-3.5-turbo",
      max_tokens: 1500,
      messages: [
        {
          role: "system",
          content: `You are a professional CV writer. Based on the conversation history provided, extract all relevant information and return a CV as a JSON object. Return ONLY valid JSON, no markdown, no explanation.

Return this exact structure:
{
  "full_name": "",
  "email": "",
  "phone": "",
  "location": "",
  "linkedin": "",
  "career_objective": "2-3 sentence professional summary",
  "work_experience": [
    {
      "company": "",
      "role": "",
      "start_date": "",
      "end_date": "",
      "responsibilities": ["bullet 1", "bullet 2", "bullet 3"]
    }
  ],
  "education": [
    {
      "institution": "",
      "degree": "",
      "field": "",
      "year": ""
    }
  ],
  "skills": ["skill 1", "skill 2"],
  "certifications": ["cert 1"],
  "languages": ["English", "French"],
  "interests": ["interest 1", "interest 2"]
}

Rules:
- Write bullet points as strong, action-verb-led achievement statements
- If information was not mentioned, use empty string "" or empty array []
- Never invent information not present in the conversation
- Polish and professionalise the language — improve grammar and phrasing
- Return ONLY the JSON object`,
        },
        ...conversationHistory,
        {
          role: "user",
          content:
            "Based on everything I've told you, please generate my CV now.",
```

### Feature 4 — Google Drive Integration

Allow users to save their CV PDF directly to Google Drive.

#### Implementation

- Use the **Google Drive REST API** via OAuth 2.0 (Google Identity Services)
- On first click of "Save to Google Drive":
  1. Trigger Google OAuth popup (scope: `https://www.googleapis.com/auth/drive.file`)
  2. On successful auth: generate the PDF blob → upload to Drive via multipart POST to `https://www.googleapis.com/upload/drive/v3/files?uploadType=multipart`
  3. File name: `CraftCV_{FullName}_{Date}.pdf`
  4. On success: show toast _"Saved to Google Drive ✓"_ with a link to open the file
  5. Store the Google OAuth token in `localStorage` for the session (re-auth if expired)
- On subsequent saves: re-use stored token (prompt re-auth only if expired)

#### Google Drive Edge Cases

- OAuth popup blocked by browser → show: _"Please allow popups for this site to connect Google Drive"_
- User denies permission → show: _"Google Drive access was denied. You can still download the PDF."_
- Upload fails → show: _"Upload to Google Drive failed. Please try again or download instead."_
- Token expires mid-session → silently re-trigger auth flow before retry
- User not signed into Google → Google's own OAuth handles this

### Feature 5 — CV History Page

Route: `/history`

- List of all previously generated CVs: date generated, version number, first line of career objective
- Each row: **"Preview"**, **"Download PDF"**, **"Save to Drive"**, **"Delete"** actions
- On "Preview": opens a modal with the full CV rendered
- On "Delete": confirmation dialog → _"Delete this CV version? This cannot be undone."_
- Pagination: 10 per page
- Empty state: _"No CVs generated yet. Head to the chat to get started."_

## Supabase Database Schema

```sql
-- Extended user profiles
CREATE TABLE profiles (
  id UUID REFERENCES auth.users(id) PRIMARY KEY,
  full_name TEXT NOT NULL,
  email TEXT NOT NULL,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- Chat messages (full conversation history)
CREATE TABLE messages (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  user_id UUID REFERENCES profiles(id) ON DELETE CASCADE,
  role TEXT NOT NULL CHECK (role IN ('user', 'assistant')),
  content TEXT NOT NULL,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- Generated CVs
CREATE TABLE cvs (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  user_id UUID REFERENCES profiles(id) ON DELETE CASCADE,
  version INTEGER NOT NULL DEFAULT 1,
  cv_data JSONB NOT NULL,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- Indexes for performance
CREATE INDEX messages_user_id_idx ON messages(user_id);
CREATE INDEX messages_created_at_idx ON messages(created_at);
CREATE INDEX cvs_user_id_idx ON cvs(user_id);

-- Row Level Security
ALTER TABLE profiles ENABLE ROW LEVEL SECURITY;
ALTER TABLE messages ENABLE ROW LEVEL SECURITY;
ALTER TABLE cvs ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Own profile only" ON profiles FOR ALL USING (auth.uid() = id);
CREATE POLICY "Own messages only" ON messages FOR ALL USING (auth.uid() = user_id);
CREATE POLICY "Own CVs only" ON cvs FOR ALL USING (auth.uid() = user_id);
```

**CV versioning**: When a user regenerates, increment `version` by 1 and insert a new row. Never overwrite old CVs.

## Edge Case Handling

| Edge Case                                            | Handling                                                                                                                                                                                                                       |
| ---------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| User clicks Generate with no messages yet            | Show toast: _"Chat with your CV coach first — tell me about yourself!"_ Do not make API call                                                                                                                                   |
| User clicks Generate with only 1–2 messages          | Allow but show warning: _"The more you share, the better your CV will be. Consider adding more detail first."_ with Continue and Generate Anyway buttons                                                                       |
| API returns empty or whitespace response             | Retry once automatically; if second attempt also fails, show: _"Something went wrong. Please try again."_                                                                                                                      |
| API returns non-JSON on CV generation                | Strip markdown fences, attempt parse; if still fails, show: _"We couldn't generate your CV this time. Try sending a few more messages and try again."_                                                                         |
| CV JSON missing key fields (name, experience)        | Render CV with placeholder: _"[Not provided]"_ for missing fields and show inline note: _"Some details are missing — continue the chat to add them, then regenerate."_                                                         |
| API rate limit (429) on chat                         | Show: _"Too many messages at once. Please wait a moment."_ with a 10-second cooldown before input re-enables                                                                                                                   |
| API timeout (>20 seconds)                            | Abort fetch, show: _"Response took too long. Please try again."_ Preserve user's message in input                                                                                                                              |
| Network offline                                      | Detect with `navigator.onLine`; show banner: _"You're offline. Messages will not send until you reconnect."_ Disable send button                                                                                               |
| Network comes back online                            | Dismiss offline banner automatically; re-enable send button                                                                                                                                                                    |
| User sends empty message                             | Trim whitespace; if empty after trim, do nothing. No API call made                                                                                                                                                             |
| User sends message while AI is responding            | Queue the message; send after current response completes. Show subtle _"Queued..."_ indicator                                                                                                                                  |
| Very long user message (>1000 chars)                 | Allow but show counter turning amber at 800, red at 950. Hard cap at 1000 with: _"Message too long. Please split into shorter messages."_                                                                                      |
| Supabase message save fails                          | Show toast: _"Message couldn't be saved to history."_ Chat still works — don't block UX                                                                                                                                        |
| Supabase CV save fails                               | Still show the CV preview and allow download. Show toast: _"Couldn't save to history. Download now to keep a copy."_                                                                                                           |
| Session expires mid-chat                             | `onAuthStateChange` fires SIGNED*OUT → show modal: *"Your session expired. Sign in again to continue — your conversation is saved."\_ → redirect to `/signin`                                                                  |
| User has 80+ messages (API token limit)              | Silently truncate to last 80 messages when building API payload. Conversation in DB is always full.                                                                                                                            |
| PDF generation fails (`jsPDF` / `html2canvas` error) | Show: _"PDF generation failed. Try refreshing the page and regenerating."_                                                                                                                                                     |
| CV too long for one page                             | Scale font size down progressively (20pt → 18pt → 16pt) to fit. If still overflowing, split into two pages.                                                                                                                    |
| Google OAuth popup blocked                           | Show: _"Please allow popups for this site to use Google Drive. Or download the PDF instead."_                                                                                                                                  |
| Google Drive upload fails                            | Show error toast + keep Download button available as fallback                                                                                                                                                                  |
| Google token expires                                 | Silently re-trigger OAuth before retry. If user cancels re-auth, show: _"Re-authentication needed to save to Drive."_                                                                                                          |
| User deletes account (settings)                      | Cascade delete all messages and CVs via DB foreign key `ON DELETE CASCADE`. Confirm with: _"This will permanently delete your account, all chats, and all CVs. This cannot be undone."_                                        |
| Two tabs open simultaneously                         | Last write wins on Supabase. No special handling needed for MVP — messages are append-only                                                                                                                                     |
| User pastes huge block of text as a message          | Accept up to 1000 chars (hard cap above). The AI will process it normally                                                                                                                                                      |
| AI responds in a different language                  | System prompt enforces English. If user writes in another language, AI responds in English and notes: _"I'll respond in English to keep your CV professional — feel free to write in whichever language is comfortable."_      |
| Mobile keyboard pushes chat input off screen         | Use `visualViewport` API to adjust chat container height when soft keyboard opens                                                                                                                                              |
| Browser back button from `/chat`                     | No confirmation dialog (MVP). Messages are already persisted.                                                                                                                                                                  |
| User refreshes page mid-generation                   | Loading overlay dismisses on refresh. CV preview is empty but last saved CV is available in `/history`                                                                                                                         |
| Regenerate clicked before first generation           | "Regenerate" button only appears after first successful generation. Not visible otherwise.                                                                                                                                     |
| Duplicate CV versions                                | Each click of Generate/Regenerate creates a new DB row with incremented version. Duplicates allowed — user manages via History page.                                                                                           |
| CV has no work experience at all                     | Omit the Work Experience section entirely from the rendered CV rather than showing an empty section. Add a chat message: _"I noticed you haven't mentioned any work experience — that's okay! Your CV will still look great."_ |
