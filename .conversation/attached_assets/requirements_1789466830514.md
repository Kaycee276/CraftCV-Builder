# Requirements Document

## 1. Application Overview

### 1.1 Application Name
CraftCV

### 1.2 Application Description
CraftCV is an AI-powered conversational CV builder where users have natural conversations with an AI career coach about their background, and the AI automatically generates a professional CV. Users can download the CV as PDF or save it directly to Google Drive, and return anytime to update their information and regenerate an improved version.

### 1.3 Tagline
「Tell your story. We'll write your CV.」

### 1.4 Brand Aesthetic
Warm editorial minimalism with black ink on off-white parchment aesthetic, resembling a premium notebook or well-designed newspaper.

### 1.5 Color Palette
- Background: #F7F4EF
- Surface: #EFEBE3
- Primary text: #111111
- Accent: #111111
- Muted text: #7A7570
- Border: #D9D3C9
- User chat bubble: #111111 background with #F7F4EF text
- AI chat bubble: #EFEBE3 background with #111111 text
- Error: #8B2020
- Success: #1A5C35

### 1.6 Typography
- Display/Brand: Cormorant Garamond (Google Fonts)
- Body/UI: Epilogue (Google Fonts)
- CV Document: EB Garamond for body text, Cormorant Garamond for name and headings

### 1.7 Logo
Wordmark only — 「CraftCV」 in Cormorant Garamond, with 「CV」 slightly bolder.

## 2. Users and Usage Scenarios

### 2.1 Target Users
Job seekers across Africa and beyond who need to create professional CVs.

### 2.2 Core Usage Scenarios
- First-time CV creation through conversational interaction
- Updating existing CV with new experiences
- Generating multiple CV versions for different applications
- Saving and managing CV history

## 4. Business Rules and Logic

### 4.1 Authentication Rules

#### 4.1.1 Sign Up Validation
- Full Name: 2-60 characters, letters and spaces only
- Email: valid email format
- Password: minimum 8 characters, at least one uppercase letter and one number
- Passwords must match
- No email confirmation required

#### 4.1.2 Sign Up Process
- Check for duplicate email
- Create user profile in database
- Redirect to /chat upon success

#### 4.1.3 Sign In Process
- Validate email and password
- Restore previous session if exists
- Redirect to /chat upon success

#### 4.1.4 Auth Guards
- /chat, /history, /settings require authentication
- Redirect to /signin if unauthenticated
- Show full-page skeleton loader while auth state resolves

### 4.2 AI Conversation Rules

#### 4.2.1 AI Behavior
- Act as warm, professional career coach
- Ask focused follow-up questions (one or two at a time)
- Probe for specific achievements and numbers
- Ask about: work experience, education, skills, certifications, languages, hobbies/interests, career objective
- Keep responses concise (2-4 sentences maximum)
- Never generate CV in chat
- Maintain context across full conversation history

#### 4.2.2 Conversation Persistence
- Save every message to database in real-time
- Load full conversation history on page load
- Send full conversation history to AI API on every request
- Cap at last 80 messages sent to API (internal limit)

#### 4.2.3 Message Handling
- Trim whitespace from user messages
- Ignore empty messages
- Queue messages sent while AI is responding
- Show typing indicator while AI is generating response
- Auto-scroll to newest message

### 4.3 CV Generation Rules

#### 4.3.1 Generation Trigger
- User clicks 「Generate My CV」 button
- Show full-screen loading overlay: 「Crafting your CV...」
- Make separate API call with CV generation prompt
- Parse JSON response
- Render CV preview
- Save to database
- Show success toast: 「Your CV is ready!」

#### 4.3.2 CV Data Structure
- Full name
- Email
- Phone
- Location
- LinkedIn
- Career objective (2-3 sentence professional summary)
- Work experience (company, role, start date, end date, responsibilities)
- Education (institution, degree, field, year)
- Skills
- Certifications
- Languages
- Interests

#### 4.3.3 CV Content Rules
- Write bullet points as action-verb-led achievement statements
- Use empty string or empty array for missing information
- Never invent information not present in conversation
- Polish and professionalize language
- Improve grammar and phrasing

#### 4.3.4 CV Versioning
- Each generation creates new database row with incremented version number
- Never overwrite old CVs
- Allow duplicate versions

### 4.4 PDF Generation Rules

#### 4.4.1 PDF Creation
- Generate PDF from CV HTML preview
- Use jsPDF and html2canvas
- File name format: CraftCV_{FullName}_{Date}.pdf

#### 4.4.2 PDF Layout
- Scale font size down progressively if content too long (20pt → 18pt → 16pt)
- Split into two pages if still overflowing after scaling

### 4.5 Google Drive Integration Rules

#### 4.5.1 OAuth Flow
- Trigger Google OAuth popup on first save
- Request scope: https://www.googleapis.com/auth/drive.file
- Store token in localStorage
- Re-use token for subsequent saves
- Re-authenticate if token expires

#### 4.5.2 Upload Process
- Generate PDF blob
- Upload via multipart POST to Google Drive API
- File name: CraftCV_{FullName}_{Date}.pdf
- Show success toast with link to file

### 4.6 Data Management Rules

#### 4.6.1 Message Storage
- Save every message (role, content, timestamp) to database
- Associate with user ID
- Load on page load

#### 4.6.2 CV Storage
- Save generated CV data as JSONB
- Store version number
- Associate with user ID
- Create new row on each generation

#### 4.6.3 Account Deletion
- Cascade delete all messages and CVs
- Require confirmation

## 5. Exception and Boundary Cases

| Scenario | Handling |
|----------|----------|
| Generate clicked with no messages | Show toast: 「Chat with your CV coach first — tell me about yourself!」 No API call |
| Generate clicked with 1-2 messages only | Show warning with Continue and Generate Anyway buttons |
| API returns empty/whitespace response | Retry once; if fails again: 「Something went wrong. Please try again.」 |
| API returns non-JSON on CV generation | Strip markdown fences, attempt parse; if fails: 「We couldn't generate your CV this time. Try sending a few more messages and try again.」 |
| CV JSON missing key fields | Render with 「[Not provided]」 placeholder + note: 「Some details are missing — continue the chat to add them, then regenerate.」 |
| API rate limit (429) | Show: 「Too many messages at once. Please wait a moment.」 10-second cooldown |
| API timeout (>20 seconds) | Abort fetch, show: 「Response took too long. Please try again.」 Preserve user message |
| Network offline | Show banner: 「You're offline. Messages will not send until you reconnect.」 Disable send button |
| Network comes back online | Dismiss offline banner, re-enable send button |
| Empty message sent | Trim whitespace; if empty, do nothing |
| Message sent while AI responding | Queue message, show 「Queued...」 indicator, send after current response |
| Very long message (>1000 chars) | Counter amber at 800, red at 950, hard cap at 1000 with: 「Message too long. Please split into shorter messages.」 |
| Supabase message save fails | Show toast: 「Message couldn't be saved to history.」 Don't block UX |
| Supabase CV save fails | Show CV preview, allow download. Toast: 「Couldn't save to history. Download now to keep a copy.」 |
| Session expires mid-chat | Show modal: 「Your session expired. Sign in again to continue — your conversation is saved.」 Redirect to /signin |
| 80+ messages in conversation | Silently truncate to last 80 messages for API payload |
| PDF generation fails | Show: 「PDF generation failed. Try refreshing the page and regenerating.」 |
| CV too long for one page | Scale font down progressively; if still overflowing, split to two pages |
| Google OAuth popup blocked | Show: 「Please allow popups for this site to use Google Drive. Or download the PDF instead.」 |
| Google Drive upload fails | Show error toast, keep Download button available |
| Google token expires | Silently re-trigger OAuth; if cancelled: 「Re-authentication needed to save to Drive.」 |
| Account deletion | Confirm with: 「This will permanently delete your account, all chats, and all CVs. This cannot be undone.」 |
| Mobile keyboard pushes input off screen | Adjust chat container height using visualViewport API |
| CV has no work experience | Omit Work Experience section + chat message: 「I noticed you haven't mentioned any work experience — that's okay! Your CV will still look great.」 |
| Regenerate before first generation | Regenerate button only visible after first successful generation |
| Duplicate email on sign up | Show: 「An account with this email already exists.」 with link to sign in |
| Wrong credentials on sign in | Show: 「Incorrect email or password.」 |
| Weak password on sign up | Show inline hint under password field |

## 6. Acceptance Criteria

1. User signs up with full name, email, and password
2. User is redirected to /chat and sees welcome message from AI coach
3. User has conversation with AI about their background and experience
4. User clicks 「Generate My CV」 button
5. CV preview appears in right panel with all information from conversation
6. User downloads CV as PDF
7. User can save CV to Google Drive (optional)
8. User can view all generated CVs in /history page
